所有撰写/审校单元的代理必须遵守本规范。

## 0. 读者与用途

- 读者：经济学博士生，数学基础一般（会矩阵与概率的基本运算，但不熟练）。
- 用途：博士资格考试（开卷、英文试卷、90 分钟）。本书打印后带入考场查阅，所以既要能学懂，又要能快速查到。
- 三项总要求：
  1. **全面**：旧版中每一个知识点、公式、推导、结论、例子、注意事项都必须保留（可合并重复，但不得丢失）。旧版目录里属于本单元的每一个条目，新版都必须有对应内容。
  2. **系统**：由浅入深、前后衔接。每个主题按“动机/直觉 → 定义 → 推导 → 例子 → 易错点 → 英文表述”组织。先讲简单情形，再讲一般情形。
  3. **透彻**：语言干练，不啰嗦也不含糊；推导每一步都写出来，右侧注明理由。

## 3. 标题与目录（考场靠目录查找，务必细致）

- 你负责的旧版各节，在新版中各对应一个 `\section`（标题可改得更准确、更简洁；可在节内调整顺序、合并重复）。
- 节内用 `\subsection`、`\subsubsection` 细分：**每一个小知识点、每一个公式性结论、每一个重要推导、每一个例子主题，都要有自己的标题**，使详细目录能当索引用。旧版目录中出现的条目，新版目录中都应能找到对应标题（措辞可改）。
- 标题要具体地说出内容，例如“组内变换消去 $\alpha_i$”“$T=2$ 时 FD 与 FE 相等”，不要写“推导”“说明”“补充”这类空标题。
- 标题中有数学时必须写成 `\texorpdfstring{$...$}{纯文本}`。
- 本章第一个单元的文件以 `\chapter{章标题}` 开头，紧跟一段“本章导读”（不加标题，3–6 行：本章解决什么问题、与前后章的关系、学习路线）。其他单元不写 `\chapter`。
- 本章最后一个单元以 `\section{本章小结}` 收尾，包含：(1) 核心公式与结论表（tabularx）；(2) 方法对照/选择要点；(3) 常见错误清单；(4) 至多 4 道最有代表性的综合练习（`prac` 盒，答案完整）。（第 17 章不需要。）

## 4. 推导的写法（最重要）

- 推导用 `align*`，**一步一行**，每行末尾用 `\why{理由}` 注明这一步的依据，理由要短（一般不超过 15 字），例如：`\why{代入 (10.3)}`、`\why{$M_T\one_T=0$}`、`\why{迭代期望律}`、`\why{WLLN 与 CMT}`、`\why{混合积性质}`、`\why{$\bar\alpha$ 与 $t$ 无关}`。
- 不跳步：转置、求逆、Kronecker 积运算、期望线性性、条件期望“提出已知量”、加一项减一项、交换求和次序……每用一次都写出来并注明理由。
- 推导前一句话说明“要证什么、思路是什么”；推导后一句话说明“这个结论意味着什么/怎么用”。
- 每个符号第一次出现时定义；矩阵标出维度（如“$X$ 为 $n\times K$”）。
- 长公式用 `aligned`、`split` 或 `multline*` 断行，不得溢出页边。带 `\why` 的行不要再加 `\tag` 或 `\label`；需要被引用的关键公式用 `equation` 并 `\label`。
- 旧版推导中若有错误（符号、转置、下标、系数、维度），改正。

## 5. 例子与练习

- `exmp`：保留旧版所有数值例与案例；解答写在 `\solution` 之后，逐步推导，关键步骤同样用 `\why`。
- `prac`（即时练习）：保留旧版正文中的练习（题目 + `\answer` 后的完整解答）。章末综合练习至多保留 4 道放进“本章小结”。不要新编大量习题；若某道被删的练习含有正文没有的知识点，把该知识点并入正文。

## 6. 盒子、标签与索引（由 `bookstyle.sty` 提供）

| 环境/命令 | 用途 |
|---|---|
| `\begin{defn}[标题]` | 定义（自动编号“定义 10.3”） |
| `\begin{thm}[标题]` | 定理/结论，写清条件与结论 |
| `\begin{exmp}[标题]` … `\solution` … | 例题、案例 |
| `\begin{prac}[标题]` … `\answer` … | 即时练习 |
| `\begin{note}[标题]` | 注意、易错点、常见误解 |
| `\begin{keypt}[标题]` | 考点提示（如“2025 真题第 1 题考到”“英文试卷常见问法”） |
| `\begin{english}` | 每个 `\section` 末尾 1 个：3–6 句可直接写进英文答卷的标准表述 |
| `\begin{extend}[标题]` | 拓展内容（超出核心但可能考到） |
| `\begin{method}[标题]` | 实证流程、检验步骤、算法步骤 |
| `\begin{summary}[标题]` | 本节要点（长节可用，可选） |
| `\tagext`、`\tagkey`、`\tagexam` | 行内小标签：拓展 / 重点 / 真题 |
| `\term{中文}{English}` | 概念首次出现：输出“**中文**（English）”并登记英文索引 |
| `\idx{English}{中文}` | 只登记索引、不输出文字 |
| `\key{...}` | 强调（少用） |
| `\why{...}`、`\whyin{...}` | 公式行右侧理由 / 行内理由 |

- 索引词中不要出现 `! @ | "` 字符。每个重要英文术语在定义处登记一次即可。
- 常用宏：`\E \Var \Cov \Corr \avar \tr \rank \diag \plim \argmin \argmax \iid \pto \dto \T`（转置，$X\T$ 显示为 $X'$）`\inv`（$^{-1}$）`\one`（粗体 1）`\R \indep`。指示函数写 `\mathbf{1}\{\cdot\}`（没有 `\mathbbm`）。

## 7. 语言

- 简洁、专业、准确；短句；不用口语（“其实”“咱们”“我们来看看”），不写空话套话。
- 先给直觉再给形式；必要时用一句话打比方，但不得牺牲准确性。
- 中文用全角标点（，。；：“”），数学与英文用半角。
- 术语与记号全书统一（以旧版第 1 章“全书统一符号速查表”和附录“全书记号对照”为准）。
- 英文术语在首次出现时给出（用 `\term`）。

## 8. LaTeX 规范与编译检查

- 单元文件里**不要**写 `\documentclass`、`\usepackage`、`\begin{document}`。只用 `bookstyle.sty` 已加载的宏包：amsmath/amssymb/mathtools/bm、tcolorbox、booktabs/tabularx/longtable/multirow/makecell、enumitem、tikz、listings、multicol。
- `\label` 一律加单元前缀：`eq:U10a-fwl`、`sec:U10a-lsdv`。只 `\ref` 本单元的 label。
- 表格用 `tabularx`（列类型 `L` = 左对齐自动换行）或 `longtable`；不要用浮动体 `table`/`figure` 的 `[h]` 以外位置参数；可用 `\captionof{table}{...}`。
- 文件很长时**分多次写入**：先用 Write 写入开头部分，再用 Bash 追加，例如
  `cat >> 文件 <<'LATEXEOF'` … `LATEXEOF`（定界符加引号，反斜杠不会被转义）。
- 编译检查（必须通过）：
  `bash /home/user/moyang-cloud-session/books/tools/check_unit.sh <单元文件绝对路径> <章号> guide "<章标题>"`
  （第 4 个参数只在文件本身不含 `\chapter` 时需要。）要求：`COMPILE OK`；Overfull 超过 10pt 的尽量消除；`BANNED-WORD CHECK: OK`。
- 生成的 PDF 路径会打印出来；可以用 `pdftoppm -f N -l N -r 80 -png <pdf> <前缀>` 渲染某页后用 Read 查看排版。
